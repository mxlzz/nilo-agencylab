# AgencyLab — Programa Nilo

**Estado: apertura documental; investigación de antecedentes pendiente.**

## Pregunta inicial (a precisar tras revisión)
¿Qué mecanismos permiten generar, seleccionar y revisar prioridades propias a partir de estado interno, experiencia y oportunidades, sin misiones externas?

## Alcance y exclusiones
Motivación, curiosidad, conflictos, preferencias, iniciativa, persistencia y abandono de objetivos. No implementar fisiología de BodyLab ni aprendizaje neuronal de NeuroLab; no llamar voluntad o conciencia a una función de recompensa.

## Independencia experimental
Estados fisiológicos sintéticos, capacidades cognitivas y acciones limitadas, entornos de oportunidades y perturbaciones controladas.
Los resultados obtenidos con sustitutos no acreditan transferencia al futuro Nilo. La arquitectura y el lenguaje son decisiones abiertas.
